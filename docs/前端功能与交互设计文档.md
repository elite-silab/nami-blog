## 1. 技术选型

| 层级     | 技术                         | 说明                                              |
| -------- | ---------------------------- | ------------------------------------------------- |
| 框架     | **Astro 5**                  | Static 模式（SSG），构建时预渲染                  |
| 前端语言 | TypeScript                   | 全量 TS，strict 模式                              |
| 部署     | **Cloudflare Pages**         | 静态资源全球分发，API 独立运行在 Workers           |

| 主题     | **三套二次元主题**           | 樱花/海洋/星空，`data-theme` + CSS 变量切换       |

| 图片优化 | `<img>` + Astro 自动优化     | `public/images/` 静态分发                         |
| 评论     | **自建评论系统**             | D1 存储，嵌套回复，敏感词过滤，管理员审核         |

| 表单验证 | Zod                          | 前后端共享校验 schema（`packages/shared`）        |

## 3. 核心功能设计

### 3.1 文章列表与分页

- 首页展示最新 10 篇文章摘要（标题 + 封面 + 摘要 + 日期 + 标签）
- 使用静态分页，每页 10 篇；超过 10 页的路径由构建阶段生成
- 分类/标签页采用同样分页策略
- 空状态：显示友好插图与引导文案

### 3.2 文章阅读

- **目录导航（TOC）**：右侧悬浮，自动从 H2/H3 生成，当前章节高亮
- **阅读进度条**：顶部细线进度指示
- **代码块**：语法高亮 + 一键复制 + 语言标签 + 行号（可选）
- **图片**：点击放大（Lightbox），懒加载，自动生成 srcset
- **系列文章**：上一篇/下一篇导航 + 系列目录侧栏
- **预计阅读时间**：按中文字数计算，显示在文章头部
- **阅读次数**：页面打开后调用专用接口写入 D1，同一标签页按文章去重；统计失败不影响正文阅读
- **文章分享**：复制链接 / Twitter / 微博一键分享
- **更新时间**：显示创建时间和最后修改时间

### 3.3 搜索

- 使用 Workers API 的 `q` 参数进行标题/正文搜索
- 搜索框支持快捷键 `Ctrl/Cmd + K` 唤起（Command Palette 风格）
- 搜索结果显示匹配文章摘要与日期
- 当前搜索页支持提交态、骨架屏、失败提示和请求竞态保护

### 3.4 评论系统（自建，已实现）

基于 D1 数据库的自建评论系统：

- **提交**：访客填写昵称、邮箱（可选）、网站（可选）和评论内容
- **审核**：支持自动通过或手动审核两种策略（通过站点设置配置）
- **敏感词过滤**：内置敏感词库，命中后自动拦截
- **嵌套回复**：支持 `parent_id` 嵌套评论
- **管理后台**：管理员可批准/拒绝/删除评论
- **API 端点**：
  - `POST /api/v1/comments` — 提交评论
  - `GET /api/v1/comments/:postId` — 获取文章已批准评论
  - `PATCH /api/admin/comments/:id/status` — 管理员审核
  - `DELETE /api/admin/comments/:id` — 管理员删除
- **前台组件**：`CommentSection.astro` — 评论列表 + 提交表单，集成到文章详情页

### 3.5 主题系统（三套二次元主题）

已实现三套二次元风格主题，通过 CSS 变量 + `data-theme` 属性切换：

| 主题    | ID       | 风格             | 主色调    | 明暗 |
| ------- | -------- | ---------------- | --------- | ---- |
| 🌸 樱花 | `sakura` | 温柔浪漫，粉色系 | `#ec4899` | 明色 |
| 🌊 海洋 | `ocean`  | 清凉通透，蓝绿色 | `#0891b2` | 明色 |
| ✨ 星空 | `starry` | 深邃宇宙，紫蓝色 | `#8b5cf6` | 暗色 |

**切换机制**：

- 默认主题：Astro 布局输出 `data-theme`，客户端从 `localStorage` 恢复用户选择
- 客户端：`localStorage` 持久化 + 即时切换
- 防闪烁：内联脚本在 `<head>` 中提前设置主题，避免闪烁
- 管理后台：卡片式可视化选择器，点击即时预览 + 自动保存

**装饰效果**：

- `.theme-header` — 主题渐变背景
- `.theme-glow` — 主题发光效果
- CSS 变量覆盖范围：主色/辅助色/背景色/文字色/边框色 + 装饰变量（渐变/发光）
- 平滑过渡动画：300ms ease，尊重 `prefers-reduced-motion`

### 3.6 RSS 订阅

- 构建时自动生成 `/rss.xml`（RSS 2.0）
- 包含全文内容、封面图、分类标签
- Header 或 Footer 放置 RSS 图标入口

### 3.7 SEO 与 Open Graph

- 每页独立 `<title>`、`<meta description>`、`canonical`
- Open Graph 标签：标题、描述、封面图、类型
- Twitter Card：`summary_large_image`
- JSON-LD 结构化数据：`BlogPosting` schema
- 自动生成 `sitemap.xml`，包含所有公开页面

## 4. 交互规范

### 4.1 加载状态

| 场景     | 处理方式                           |
| -------- | ---------------------------------- |
| 首次加载 | 骨架屏（Skeleton），与真实布局一致 |
| 分页加载 | 底部 Spinner + "加载中…" 文案      |
| 图片加载 | 模糊占位图（BlurHash / LQIP）渐显  |
| 搜索中   | 表单提交 + 骨架屏 + 按钮 loading 态 |

### 4.2 错误处理

| 场景         | 处理方式                |
| ------------ | ----------------------- |
| 网络异常     | Toast 提示 + 重试按钮   |
| 404 页面     | 趣味插画 + 返回首页按钮 |
| 评论加载失败 | 折叠区域 + "点击重试"   |
| 图片加载失败 | 灰色占位 + alt 文字     |

### 4.3 动画与过渡

- **页面切换**：`view-transition-api`（支持浏览器）淡入淡出
- **列表项进入**：交错渐入（stagger 50ms）
- **悬停反馈**：卡片微上浮（translateY -2px）+ 阴影增强
- **按钮点击**：缩放反馈（scale 0.97）
- **原则**：所有动画 ≤ 300ms，尊重 `prefers-reduced-motion`

### 4.4 响应式断点

| 名称  | 宽度   | 说明              |
| ----- | ------ | ----------------- |
| `sm`  | 640px  | 手机横屏          |
| `md`  | 768px  | 平板竖屏          |
| `lg`  | 1024px | 平板横屏 / 小桌面 |
| `xl`  | 1280px | 标准桌面          |
| `2xl` | 1536px | 大屏              |

### 4.5 无障碍（A11y）

- 语义化 HTML 标签（`<article>`、`<nav>`、`<aside>`）
- 所有交互元素可通过键盘访问（Tab / Enter / Esc）
- 图片均有有意义的 `alt` 文本
- 颜色对比度 ≥ WCAG AA（4.5:1 正文，3:1 大字）
- `aria-label` 用于图标按钮和无文本链接
- 焦点可见（`:focus-visible` 自定义 outline）

## 5. 性能目标

| 指标                           | 目标值                               |
| ------------------------------ | ------------------------------------ |
| LCP (Largest Contentful Paint) | ≤ 2.0s                               |
| FID (First Input Delay)        | ≤ 50ms                               |
| CLS (Cumulative Layout Shift)  | ≤ 0.05                               |
| TTFB (Time to First Byte)      | ≤ 200ms（Cloudflare 边缘缓存）       |
| 首页总体积                     | ≤ 300KB（压缩后，不含图片）          |
| 字体                           | `font-display: swap`，子集化中文字体 |

### 性能策略

- 关键 CSS 内联，非关键 JS 延迟加载
- 图片全部懒加载 + 响应式尺寸
- Cloudflare Cache Rules：静态资源长期缓存，HTML 按 TTL 刷新
- 预连接关键第三方域名（`<link rel="preconnect">`）
- Service Worker 离线缓存（可选，PWA 阶段实现）

## 7. 当前实现基线（2026-07）

### 7.1 视觉方向

- 视觉关键词：编辑感、边缘网络、轻二次元、安静但有记忆点。
- 首页以“主推文章”作为视觉锚点，下面接最近文章和主题探索，不使用信息密度过高的仪表盘式布局。
- 标题使用 `--font-display`（衬线展示字体），正文使用 `--font-sans`，颜色全部来自主题 CSS 变量。
- 主题背景使用网格和渐变装饰；动效必须尊重 `prefers-reduced-motion`。

### 7.2 全局交互

- 所有页面提供“跳到主要内容”链接和可见键盘焦点。
- 页面滚动时显示顶部阅读进度条，滚动超过阈值显示“回到顶部”按钮。
- 移动端导航通过汉堡按钮展开，点击链接后自动收起。
- 搜索、评论等异步区域必须提供 loading、空状态、错误状态和可重试动作。

### 7.3 Cloudflare 运行约束

- 前端是 SSG：文章、分类和友链等公开内容在 Pages 构建时请求 Workers API。
- 内容更新后需要重新构建/部署 Pages 才会反映到静态页面；评论提交和评论读取为浏览器端实时请求。
- API 健康检查：`GET /api/v1/healthz`；本地默认地址为 `http://localhost:8788`。
- API 返回的公开 GET 资源允许短时边缘缓存；管理接口、登录接口和健康检查不得缓存。
