Nami Blog v0.1.1 是首个公开版本之后的稳定性更新，重点修复 Slug 生成和中文文章地址无法打开的问题。

## 本次更新

- 中文文章标题自动转为无声调小写拼音 Slug，例如“成功部署”生成 `cheng-gong-bu-shu`。
- 修复输入标题时 Slug 只保留第一个字的问题。
- 文章、分类和标签统一使用小写英文、数字和连字符的 Slug 规则。
- 旧版本中已保存的中文 Slug 仍可继续访问，无需迁移 D1 数据。
- 分类和标签新建弹窗会根据名称自动生成拼音 Slug。
- API 增加 Slug 格式、唯一性校验和易懂的中文错误提示。
- README 的首页与管理后台截图已更新，并改为竖向排列。
- 页脚新增 `v0.1.1` 版本号，方便确认当前部署版本。

## 升级说明

本版本不包含新的 D1 迁移，也不需要新增 Cloudflare 环境变量。同步 `main` 分支并重新部署即可。
