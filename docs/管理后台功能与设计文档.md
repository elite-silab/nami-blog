## 1. 概述

管理后台为博主提供内容管理、站点配置和数据查看能力。采用独立路由前缀 `/admin`，页面由 Astro 静态生成，权限边界统一由 Workers API 鉴权。

### 1.1 技术选型

| 层级     | 技术                      | 说明                                        |
| -------- | ------------------------- | ------------------------------------------- |
| 框架     | **Astro 5**               | 与前台同应用，`/admin/*` 路由组             |
| UI       | **Tailwind CSS 4**        | CSS 变量主题系统，复用设计 token            |
| 鉴权     | **JWT** (jose + bcryptjs) | Cookie + 标签页 Bearer 回退，Refresh Token 轮换 |
| API 消费 | Workers fetch             | `PUBLIC_API_URL` 指向独立 API                 |
| 表单     | 原生 HTML + JS            | 轻量实现，服务端边界校验                     |

### 1.2 权限模型

MVP 仅支持**单博主（管理员）**角色，不开放注册：

- 所有 `/api/admin/*` 接口均通过 Workers 中间件校验 JWT
- 管理页面遇到 401 时尝试轮换会话，失败后跳转 `/admin/login`
- API 层 Workers 中间件校验 access token、issuer、audience、角色和账号状态
- 本地开发的空数据库可使用根目录 `.env` 中 `ADMIN_INITIAL_PASSWORD` 首次登录，账号固定为 `admin`
- 生产空数据库可使用 Workers Dashboard 中至少 12 个字符的一次性 Secret 通过 HTTPS 初始化；公开的本地模板密码会被拒绝
- 两种初始化都不会覆盖已有管理员；生产首次登录改密后应删除一次性 Secret

## 3. 核心功能设计

### 3.1 仪表盘（Dashboard）

**数据卡片**（首行 4 宫格）：

| 卡片       | 数据                    | 说明                         |
| ---------- | ----------------------- | ---------------------------- |
| 文章总数   | 已发布 + 草稿           | 不统计软删除文章             |
| 评论总数   | 总数 + 待审核数         | 待审核标红                   |
| 总浏览量   | 公开文章累计阅读次数    | D1 `view_count` 汇总          |
| 分类与标签 | 分类总数 + 标签总数     | 不统计软删除分类和标签       |

阅读量由文章页运行时调用专用接口记录，同一浏览器标签页按文章去重。它是适合轻量博客的页面阅读次数，不等同于 Cloudflare Analytics 的独立访客数。

**快捷操作区**：

- 写新文章、审核评论、上传媒体（3 个大按钮）
- 最近 5 条待审核评论预览

**最近活动**：

- 最近发布/修改的 5 篇文章（可点击跳转编辑）

### 3.2 文章管理

#### 文章列表

- **表格列**：标题、分类、标签、状态、创建时间、更新时间、浏览量、操作
- **筛选**：按状态（全部/已发布/草稿）、分类、标签、时间范围
- **搜索**：标题模糊搜索
- **排序**：默认按更新时间倒序，可切换创建时间/浏览量
- **批量操作**：批量发布、批量删除（二次确认弹窗）
- **分页**：每页 20 条，底部分页器

#### 文章编辑器

```
┌─────────────────────────────────────────────────┐
│  ← 返回    文章标题输入框（大字号）    保存草稿 │ 发布 │
├─────────────────────────────────────────────────┤
│  工具栏：B I H2 H3 Link Image Code Quote List  │
├─────────────────────┬───────────────────────────┤
│                     │  侧边配置面板              │
│  Markdown / WYSIWYG │  · 封面图上传             │
│  编辑区域            │  · 摘要输入               │
│                     │  · 分类选择               │
│                     │  · 标签选择/新建           │
│                     │  · URL Slug 编辑          │
│                     │  · 是否置顶               │
│                     │  · 是否公开               │
│                     │  · 定时发布               │
├─────────────────────┴───────────────────────────┤
│  字数统计 · 预计阅读时间 · 自动保存状态          │
└─────────────────────────────────────────────────┘
```

- **Markdown 工具栏**：标题、粗体、引用、链接和代码块快捷插入
- **标签页草稿**：新建文章输入后短延迟暂存到 `sessionStorage`，重新打开可选择恢复
- **离开保护**：服务器保存前离开或刷新会触发浏览器确认
- **封面图**：支持输入仓库静态图片路径或外部 URL
- **Slug 自动生成**：根据标题自动生成，可手动修改
- **写作反馈**：实时字数、预计阅读时间、保存中禁用和页面内成功/错误状态
- **静态路由兼容**：新增文章和草稿无需重新构建 Pages 即可进入管理编辑页

### 3.3 分类管理

- 树形结构（支持最多 2 级）
- 字段：名称、Slug、描述、排序权重、图标（可选）
- 显示关联文章数
- 删除分类前检查：有文章关联时提示迁移

### 3.4 标签管理

- 平铺列表视图
- 字段：名称、Slug、颜色标记
- 支持合并标签（将 A 标签的文章全部迁移到 B）
- 批量删除无文章关联的空标签

### 3.5 评论管理（已实现）

基于自建评论系统，管理后台提供完整的评论审核功能：

- **三个 Tab**：全部 / 待审核 / 已批准
- **列表信息**：评论内容、评论者昵称/邮箱、所属文章、时间、状态
- **操作**：批准（`PATCH /api/admin/comments/:id/status`）、拒绝、删除（`DELETE /api/admin/comments/:id`，软删除）
- **快捷筛选**：按文章筛选、按时间范围
- **数据来源**：D1 `comments` 表，支持 `parent_id` 嵌套回复

### 3.6 图片管理

- **存储方式**：图片直接存放在仓库 `public/images/` 目录，通过 Git 管理版本
- **上传流程**：通过 Git 提交图片文件到 `public/images/`，或使用外部图床 URL
- **引用方式**：文章中使用绝对路径引用，如 `/images/post-cover.png`
- **格式限制**：jpg/png/gif/webp/svg，单文件建议 ≤ 500KB
- **优化**：构建时 Astro 自动优化图片（WebP 转换、响应式 srcset）

### 3.7 友链管理

- 列表字段：站名、URL、头像、描述和排序
- 友链由管理员添加，保存后立即公开并触发 Pages 更新
- 支持编辑和删除，不设置审核状态、通过操作或链接可用性检查
- 数据库保留旧状态字段以兼容已有 D1，但后台和公开页面不再使用

### 3.8 站点设置

分 Tab 组织：

| Tab  | 配置项                                            |
| ---- | ------------------------------------------------- |
| 基础 | 站点名称、副标题、Logo、Favicon、版权信息         |
| SEO  | 默认 meta description、关键词、Google/Bing 验证码 |
| 社交 | GitHub / Twitter / 邮箱等社交链接                 |
| 外观 | **主题切换**（🌸 樱花 / 🌊 海洋 / ✨ 星空）       |
| 安全 | **修改密码**（当前密码 + 新密码 + 确认密码）      |
| 评论 | 评论系统开关、审核策略（自动/手动）、敏感词列表   |
| 数据 | JSON 备份导出与导入                              |
| 高级 | 规划中：自定义 CSS；暂不开放任意 JS 注入         |

- 配置写入 D1 后立即对 API 生效；公开配置保存后由 Worker 的 Pages Deploy Hook 自动触发静态前台重建
- 主题卡片点击只进行预览，点击“保存设置”才写入 D1 并触发一次前台更新，避免连续切换产生多次部署
- 数据备份包括文章、分类、标签、关联、评论、友链和站点设置；不包括账号密码、Token、访问隐私和 Git 图片
- 导入前完整校验格式与关联关系，再通过 D1 事务批量替换内容数据；失败自动回滚，当前管理员账号保持不变
- 敏感操作（如清空数据）需二次确认

## 4. 交互规范

### 4.1 表单

- 标签左对齐，输入框右对齐（表单宽度 ≤ 640px 时上下排列）
- 必填字段红色星号标记
- 实时校验：失焦时校验 + 提交时全量校验
- 错误信息内联显示在字段下方，红色文字
- 提交按钮在请求中显示 loading spinner 并禁用

### 4.2 确认操作

- 删除操作：二次确认弹窗，显示将被删除的内容摘要
- 不可逆操作（如清空数据）：需输入确认文字（如输入 "DELETE"）
- 批量操作：显示选中数量，确认后执行

### 4.3 通知反馈

| 类型 | 方式                         | 示例                                  |
| ---- | ---------------------------- | ------------------------------------- |
| 成功 | Toast（右下角，可手动关闭）  | "已保存，前台正在自动更新"           |
| 错误 | Toast（右上角，需手动关闭）  | "保存失败，请重试"                    |
| 警告 | 弹窗确认                     | "有 3 篇文章引用了此分类，确认删除？" |
| 信息 | Banner（页面顶部）           | "有 5 条评论待审核"                   |

### 4.4 数据表格

- 空状态：居中图标 + 文案 + 操作按钮
- 加载中：表格区域骨架屏
- 行悬停高亮
- 操作列固定在右侧
- 支持列宽调整（可选）

### 4.5 快捷键

| 快捷键             | 操作            |
| ------------------ | --------------- |
| `Ctrl/Cmd + S`     | 保存当前编辑    |
| `Ctrl/Cmd + Enter` | 发布文章        |
| `Ctrl/Cmd + K`     | 全局搜索        |
| `Esc`              | 关闭弹窗/侧边栏 |
| `?`                | 显示快捷键帮助  |

## 5. 安全设计

- **登录限流**：应在 Cloudflare WAF/Rate Limiting 层配置；Workers 当前只负责认证校验
- **CSRF**：Cookie 使用 HttpOnly、SameSite；跨站默认域名通过 Bearer Token 调用，并继续受 CORS 白名单约束
- **XSS 防护**：评论链接仅允许 `http/https`，回复操作不使用内联 JavaScript；文章 HTML sanitizer 仍是后续工作
- **密码安全**：bcrypt 加密存储，修改密码需验证旧密码
- **初始凭据**：由部署时 bootstrap 流程生成，不写入仓库或文档
- **敏感日志**：禁止记录 Authorization、Cookie、密码和 token；审计日志表已预留，业务写入逐步补齐
- **Session 管理**：Access Token 15 分钟过期，Refresh Token 7 天并单次轮换，带 `token_use`、issuer、audience

## 6. 当前交互基线（2026-07）

### 6.1 登录与会话

- 登录成功后写入 HttpOnly Cookie；HTTPS 环境追加 `Secure`。
- 为兼容 `pages.dev` 与 `workers.dev` 的跨站部署，令牌同时保存在当前标签页的 `sessionStorage`，关闭标签页即清除。
- Access Token 失效时只发起一次刷新请求；服务端吊销旧 Refresh Token，再签发新令牌。
- 登录页展示明确的提交中、失败和跳转状态，不在页面中保存密码。
- 退出和修改密码会吊销对应 Refresh Token，再返回登录页。

### 6.2 内容管理

- 文章列表支持草稿/已发布筛选、分页、编辑和软删除。
- 编辑入口使用 `/admin/posts/edit?id=<id>` 固定静态页，不依赖构建期文章 ID。
- 新建页支持标签页草稿恢复；编辑器支持 Markdown 工具栏、`Ctrl/Cmd + S`、离开保护、字数与阅读时间。
- 发布前应确认标题、正文、状态和公开开关；`is_public = 0` 的文章不会出现在公开 API。
- 发布、修改、取消公开或删除公开文章后会触发 Pages 重建；草稿和非公开文章不触发。
- 后台区分“正在更新”“尚未配置”“触发失败”三种状态；部署失败不回滚已经保存到 D1 的内容。

### 6.3 移动端验收标准

- 375px 宽度下侧栏不占据主内容，菜单可打开/关闭。
- 打开抽屉后点击遮罩、导航链接或返回键语义等价地关闭菜单。
- 所有菜单按钮可键盘聚焦，并通过 `aria-expanded` 反映状态。
