# 管理后台功能与设计

## 定位

管理后台位于 `/admin`，与公开站点和 API 一起运行在同一个 Cloudflare Worker。它提供内容、互动、站点设置和数据备份能力。

## 路由

| 路由 | 功能 |
| --- | --- |
| `/admin/login` | 登录 |
| `/admin` | 仪表盘 |
| `/admin/posts` | 文章列表 |
| `/admin/posts/new` | 新建文章 |
| `/admin/posts/edit?id=:id` | 编辑文章 |
| `/admin/categories` | 分类 |
| `/admin/tags` | 标签 |
| `/admin/comments` | 评论审核 |
| `/admin/friends` | 友链 |
| `/admin/settings` | 站点设置、备份、密码 |

固定的编辑页配合查询参数，任何新文章和草稿都可直接编辑，不依赖构建时生成路由。

## 登录与会话

1. 用户提交用户名和密码到 `/api/v1/auth/login`。
2. API 返回短期 Access Token 和长期 Refresh Token，并设置 HttpOnly Cookie。
3. 当前标签页同时在 `sessionStorage` 保存会话，刷新页面后仍可使用。
4. 管理请求遇到 401 时自动刷新一次并重试。
5. 刷新失败则清除本地会话并返回登录页。

同源部署不依赖第三方 Cookie。退出和修改密码会清除会话；已有管理员密码不受 `ADMIN_INITIAL_PASSWORD` 后续变化影响。

## 仪表盘

展示真实可计算数据：

- 已发布与草稿文章数
- 评论总数与待审核数
- 公开文章累计浏览量
- 分类与标签数量
- 最近文章和待审核评论

不展示无法可靠计算的虚假“存储用量”。Cloudflare 配额应以 Dashboard 为准。

## 文章管理

### 列表

- 全部、已发布、草稿筛选
- 标题、置顶、状态、阅读量、更新时间
- 分页
- 编辑和二次确认删除

### 编辑器

- Markdown 正文
- 中文标题自动转为小写拼音 Slug，用户手动修改后不再覆盖
- 标题、粗体、引用、链接和代码快捷按钮
- 分类、标签、摘要、封面 URL
- 置顶、公开、草稿、发布和归档状态
- 字数与预计阅读时间
- `Ctrl/Command + S` 保存
- 未保存离开保护
- 新建文章标签页临时草稿恢复

保存接口返回 `publication.status`：

- `live`：D1 公开变化已保存，并已请求清理公开 KV 缓存
- `not_needed`：草稿等非公开变化无需更新前台

不显示“正在重新部署”之类旧静态架构提示。

## 分类、标签和友链

三者复用 Resource Manager：

- 列表、空状态、创建、编辑和删除
- 弹窗固定居中
- 移动端安全边距
- 点击遮罩或关闭按钮退出
- 无顶部彩色条

分类包含名称、Slug、描述和排序；非空分类删除前提示迁移文章。标签包含名称、Slug 和颜色。分类和标签名称会自动生成拼音 Slug，与文章统一只允许小写英文、数字和连字符。

友链由站长直接添加，保存后立即公开。不提供待审核、通过状态或自动链接检查。

## 评论管理

- 全部、待审核、已批准筛选
- 批准、拒绝、删除
- 显示昵称、内容、文章和时间
- 删除需确认

公开提交时由 API 处理评论开关、自动批准、敏感词与基础反机器人逻辑。

## 站点设置

### 基础和 SEO

- 站点名称
- 副标题
- Meta Description
- GitHub、Twitter/X、邮箱

### 首页内容

- 顶部标语
- 主标题与强调标题
- 首页简介
- “阅读文章”和“关于页”两个按钮的文字
- 一键恢复项目当前默认文案；恢复后仍需点击“保存设置”

首页采用固定结构，不开放自由拖拽和任意组件，以保证桌面端、移动端和无障碍体验稳定。

### 关于页

- 使用 Markdown 编辑完整正文
- 未自定义时，根据当前站点信息生成默认介绍
- 一键恢复默认内容；恢复后仍需点击“保存设置”
- 服务端限制内容长度并拒绝错误数据类型
- 前台渲染结果经过安全清理，不直接执行正文中的 HTML 或脚本

### 主题

- 樱花、海洋、星空
- 点击即时预览
- 保存到 D1 后主动清理访客侧公开 KV 缓存
- 访客明暗偏好独立保存

### 评论

- 是否启用评论
- 是否自动批准
- 每行一个敏感词

评论关闭时文章页隐藏评论 UI，API 同时拒绝提交。

### 修改密码

- 校验当前密码
- 新密码至少 8 位
- 成功后清除当前会话并要求重新登录

## 备份

### 导出

下载版本化 JSON，包含：

- 文章、分类、标签和关联
- 评论
- 友链
- 允许列表中的站点设置

不包含管理员、密码哈希、JWT、Cookie、IP、审计日志和图片文件。

### 导入

1. 浏览器先检查文件类型、大小和 JSON 语法。
2. API 校验版本、表、数量、字段、唯一键和关联关系。
3. 全部通过后执行事务式替换。
4. 管理员账号保持不变。
5. 成功后公开内容写入 D1，并清理对应的公开缓存。

导入前必须二次确认。

## 导航与响应式

- 桌面：固定左侧栏
- 移动：按钮打开窄屏抽屉，可通过关闭按钮、遮罩、导航或 Escape 退出
- 顶部显示当前栏目、主题切换和退出
- 后台路由不显示公开 Header/Footer
- 加载登录状态时展示验证页，避免先闪出受保护内容
- 320px 至 430px 宽度不产生页面级横向滚动
- 手机端文章、分类、标签和友链使用信息卡，桌面端保留高密度表格
- 手机端写作工具栏可横向容纳操作，保存栏固定在安全区上方
- 设置页操作按钮允许换行或占满一行，主题选择保持紧凑三列
- 弹窗限制为动态视口高度，内容过长时在弹窗内部滚动

## 错误处理

- 表单保留用户输入
- API 业务错误显示可理解文案
- 网络错误提供重试或保留状态
- 删除/导入必须确认
- 401 自动刷新一次，避免无限循环
- 全局 API 500 不向浏览器泄露内部异常

## 权限边界

- 所有 `/api/admin/*` 由中间件验证 JWT
- 管理员身份从 Token 获取，不接受客户端指定
- Secret 不进入 Next 客户端代码
- 备份字段使用允许列表
- 公开设置接口只返回安全字段，不返回自动批准和敏感词
