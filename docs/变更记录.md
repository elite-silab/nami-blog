# 变更记录

## 2026-07-27 · Workers KV 公开读缓存

- 单 Worker 新增自动配置的 `CACHE` KV binding，D1 继续作为唯一真实数据源。
- 非搜索文章列表、文章详情、分类、标签、友链和公开设置使用 cache-aside。
- 搜索、浏览量、评论、后台、认证、草稿、Secret、访客隐私和备份不进入 KV。
- 后台公开内容保存成功后清除版本化缓存；KV 故障自动回退 D1，不影响发布。
- 公开 API 增加 `X-Nami-Cache: HIT | MISS | BYPASS` 诊断头。

## 2026-07-27 · Next.js 单 Worker 架构

- 前台从 Astro 迁移到 Next.js 16 App Router，并通过 OpenNext for Cloudflare 构建。
- Next.js 前台、管理后台、Hono API 和静态资源统一部署到一个名为 `nami-blog` 的 Worker。
- 生产地址确认为 `https://nami-blog.codeelite.workers.dev`。
- 删除独立 API Wrangler 配置、Pages Functions、CORS、Deploy Hook 和静态内容重建逻辑。
- 浏览器统一请求同源 `/api/*`；Server Components 直接在 Worker 内部调用 Hono。
- 文章、分类、标签、友链、主题和站点设置写入 D1 后实时生效。
- RSS 补齐 `content:encoded` 命名空间，Sitemap、robots、canonical 和分享地址统一读取正式站点 URL。
- 新增居中资源弹窗、后台写作保护、备份导入导出、评论开关和动态主题。
- 本地开发统一使用根目录 `.env` 和端口 `4322`，生产公开地址来自根目录 `wrangler.jsonc`。
- OpenNext 开发环境与 Wrangler migrations 统一使用根目录 `.wrangler` D1 状态，并显式加载根目录 `.env`。
- 已知旧默认管理员被安全禁用后，可用当前 `ADMIN_INITIAL_PASSWORD` 一次性升级；普通禁用管理员不可借此重置。
- 完整测试、类型检查、Lint、Next 构建、OpenNext 构建和 Wrangler dry-run 纳入发布验收。

> 以下条目记录迁移前的历史实现，其中 Pages、独立 API Worker、Astro 和 Deploy Hook 已不再适用于当前部署流程。

## 2026-07-26 · 公开内容自动更新与文章列表修复

- 修复文章归档页请求 `limit=500` 超过 API 最大值 `100`、导致 Pages 部署成功但 `/blog/` 显示空列表的问题。

- Pages 构建请求增加单次构建标记以避开旧 API 缓存；生产构建读取 API 失败时直接失败，不再静默发布空页面。
- 后台增加正在更新、未配置和触发失败提示；主题选择改为先预览、保存时统一触发更新。
- 删除管理弹窗顶部高饱和渐变装饰条，保留简洁边框与柔化遮罩。

## 2026-07-25 · Cloudflare 运行与交互升级

### 运行时与 API

- 新增 `GET /healthz` 和 `GET /api/v1/healthz` 健康检查。
- 增加统一 404/500 JSON 响应，生产错误不返回堆栈。
- 公开文章接口统一过滤 `status = published`、`is_public = 1` 和软删除数据。
- 分类、标签文章数只统计公开已发布文章。
- 公开 GET 接口增加短时 `Cache-Control`；登录、评论提交、后台接口和健康检查不应缓存。
- 本地 API 默认端口统一为 `8788`，前端通过 `PUBLIC_API_URL` 连接 Workers。

### 前台体验

- 首页改为“主推文章 / 最近文章 / 主题探索”三段式编辑感布局。
- 新增可复用文章卡片组件 `apps/web/src/components/PostCard.astro`。
- 全局增加跳过导航、可见焦点、阅读进度条、回到顶部按钮和减少动效支持。
- 文章归档页增加搜索入口、分页语义和统一空状态。
- 搜索页增加表单提交、加载骨架、竞态保护和 `aria-live` 状态。
- 评论区增加骨架屏、字数统计、提交状态、无障碍提示和隐藏反垃圾字段。

### 管理后台体验

- 桌面端保持固定侧栏，移动端改为抽屉式侧栏。
- 增加遮罩关闭、导航后自动收起和 `aria-expanded` 状态。
- 后台内容区域在手机宽度下使用更紧凑的内边距。

### 安全与迁移

- 评论链接限制为 `http/https`，回复按钮不再使用内联 JavaScript。
- JSON-LD 内容写入脚本前转义 `<`、`>`、`&`。
- JWT 增加 `token_use`、issuer、audience；后台只接受 access token。
- HTTPS Cookie 增加 `Secure` 属性。
- `0003_seed_admin.sql` 不再写入固定默认管理员密码。
- `0004_disable_known_default_admin.sql` 会禁用仍使用公开默认哈希的旧账号。
