# 友链页与首页统计优化方案

## 问题

友链卡片作为 CSS Grid 子项时保留了长文本的最小内容宽度。手机端卡片被描述撑到约 1000px，导致整页横向溢出；桌面端又使用单行截断，无法完整阅读介绍。

首页第三个统计项“部署 / Worker”是架构信息，对普通访客没有阅读价值，也和“已发布、分类”两个内容指标不一致。

## 方案

1. 友链页采用编辑感访客名片布局。
2. 卡片和内部文本显式允许收缩与换行，不产生页面级横向滚动。
3. 每张卡片展示头像、名称、域名、完整描述和外链提示。
4. 外部头像加载失败时自动切换为站点名称首字，避免破图。
5. 小屏单列，768px 以上双列；页面最大宽度增加，减少桌面空旷感。
6. 空状态使用明确标题和说明，不只展示一个图标。
7. 首页并行读取标签列表，将“部署 / Worker”替换为“标签 / 数量”。

## 验收

- 375px 手机视口的页面宽度等于视口宽度。
- 长中文、英文、URL 和 Emoji 描述均可自然换行。
- 头像 URL 失效时不显示破图。
- 桌面端两列卡片视觉均衡，描述可完整阅读。
- 首页统计依次为已发布、分类、标签。
