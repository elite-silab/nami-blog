# 真实阅读统计与仪表盘指标设计

## 目标

后台不再展示无法使用的占位指标。文章详情页在访客真实打开时记录一次阅读，仪表盘展示 D1 汇总阅读量，并以分类和标签数量替换无法从 Worker 准确读取的仓库静态文件用量。

## 方案

- `GET /api/v1/posts/:slug` 只读取文章，不再因 Pages 构建而增加浏览量。
- 新增 `POST /api/v1/posts/:slug/view`，仅为公开且已发布的文章增加一次 `view_count`，返回更新后的计数。
- 文章详情页加载后调用统计接口；同一浏览器标签页使用 `sessionStorage` 按 Slug 去重。
- 统计失败不阻塞文章阅读，也不在页面弹出错误；下一次重新打开页面时可以重试。
- 后台仪表盘从 D1 汇总公开文章的 `view_count`，并统计未删除的分类和标签数量。
- 删除“CF Analytics 接入中”和“存储用量”占位文案。

## 边界

该指标表示轻量级页面阅读次数，不等同于 Cloudflare Analytics 的独立访客数。客户端去重用于减少同一标签页刷新造成的重复统计，不作为防刷系统；需要更严格的分析时仍应使用 Cloudflare Web Analytics。

## 验收

- Pages 构建和公开文章详情查询不会增加阅读量。
- 首次打开文章会增加一次阅读并更新页面数字，同一标签页刷新不重复增加。
- 草稿、非公开或不存在的文章不能增加阅读量。
- 后台显示真实总阅读量、分类数量和标签数量，不再出现两个破折号占位卡。
