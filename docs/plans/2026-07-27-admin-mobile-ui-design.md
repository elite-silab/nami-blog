# 管理后台移动端界面优化方案

## 目标

让 320px 至 430px 宽度的手机可以顺畅完成后台导航、文章管理、内容编辑、评论处理和站点设置，同时保持现有桌面端布局与视觉风格。

## 设计方向

后台继续采用克制、清楚的编辑部工具风格。移动端不缩小整套桌面界面，而是重新安排信息优先级：顶部栏只保留菜单、当前页面和两个必要操作；列表由宽表格切换为纵向信息卡；编辑器把标题、工具栏、正文和保存操作改为适合拇指操作的单列结构。

## 具体调整

1. 管理后台 Shell
   - 使用动态视口高度和安全区内边距。
   - 抽屉宽度不超过手机可用宽度，增加明确关闭按钮和 Escape 关闭。
   - 打开抽屉时锁定页面滚动。
   - 窄屏隐藏“退出”文字但保留可访问名称，标题允许截断。
   - 新建和编辑文章显示准确的顶部标题。

2. 列表与资源管理
   - 文章、分类、标签和友链在手机端使用卡片，不要求横向拖动表格。
   - 筛选、分页和新建按钮允许换行或占满一行。
   - 评论元信息与操作区在手机端分行显示。

3. 写作与设置
   - 编辑器标题字号、内边距和工具栏针对手机缩小。
   - 快捷键说明在手机端隐藏，保存栏改为可换行的安全区布局。
   - 设置卡片减小手机内边距；分区标题与恢复默认按钮上下排列。
   - 主题卡在手机端保持三列紧凑选择，备份和密码按钮扩大点击区域。
   - 弹窗限制最大高度并允许内部滚动，避免软键盘遮挡表单。

## 验收

- 320×700、390×844 和桌面视口不出现页面级横向滚动。
- 抽屉可通过按钮、遮罩、导航和 Escape 关闭。
- 写作页标题、工具栏和底部操作不截断、不互相覆盖。
- 手机端列表无需横向拖动即可看到主要信息和操作。
- TypeScript、Lint、Web 测试、完整测试和 Worker 构建通过。
