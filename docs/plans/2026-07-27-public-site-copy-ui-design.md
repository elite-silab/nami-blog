# 前台文案与 UI 优化设计

## 目标

在不改变单 Worker 架构、主题配置和后台内容管理方式的前提下，把公开站点统一为“Nami 海上手记”式的阅读体验。

## 问题

- 英文装饰词与中文主文案混用，语气不统一。
- 首页完成度较高，搜索、分类、关于和文章详情仍接近默认模板。
- 文章卡片、空状态、按钮、页面标题的间距和圆角层级不一致。
- 部分文案面向开发者介绍技术实现，不符合访客的阅读场景。

## 设计原则

1. 主要信息使用自然中文，仅保留 Nami 品牌名。
2. 使用“航线、海风、沿途、手记”等轻量意象，不让装饰词干扰内容。
3. 封面、标题和正文是文章页的主角，技术栈仅在关于页作为补充。
4. 小屏默认单列，可点击区域不小于 40px，长标题和长链接不撑宽页面。
5. 复用现有颜色 Token，同时支持樱花、海洋、星空与明暗模式。

## 页面调整

- 首页：优化品牌开场、主推文章、最新文章与分类入口。
- 归档：统一页面开场、文章卡片、分页和空状态。
- 文章详情：增强标题、阅读信息、封面、正文、分享和上下篇的层级。
- 搜索：增加使用提示、结果数量和可恢复空状态。
- 分类与标签：复用统一的文章摘要卡片。
- 友链与关于：去掉生硬英文标签，保持与首页一致的页头。
- 导航与页脚：明确当前栏目、优化移动菜单，页脚改为面向读者的站点落款。

## 验收

- 320px、390px 和 1440px 宽度下无页面级横向滚动。
- 主题色、暗色模式、键盘焦点和减少动效设置仍然有效。
- 首页、归档、文章、搜索、友链、关于和 404 使用一致语气。
- 类型检查、测试和 Worker 构建通过。
