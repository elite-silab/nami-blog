# 友链、网站备份与 RSS 实现记录

> 这是 Next.js 单 Worker 迁移前的历史记录。文中的 Astro 和 Pages 已不再用于当前项目。

## 目标

这次改动解决了三个问题：

- 友链由站长直接添加，不再经过“待审核”和“链接检查”。
- 管理后台可以直接导出和导入网站数据，无需命令行。
- RSS 输出补齐 XML 命名空间，避免阅读器报错。

## 实现内容

### 友链

- 后台保存友链后直接公开。
- 前台返回所有未删除友链，兼容早期已有数据。
- 界面移除审核状态、通过按钮和链接检查。

### 备份与恢复

- 备份包含文章、分类、标签、评论、友链和可公开的站点设置。
- 密码、管理员账号、登录令牌、IP 和日志不会导出。
- 导入前先检查文件格式、数量、唯一标识和关联关系。
- 只有全部检查通过后才替换当前内容，避免损坏原有数据。

### RSS

- RSS 根节点声明 `content` 命名空间。
- 文章正文为空时仍输出合法 XML。
- 增加回归测试，防止后续修改再次破坏 RSS。

## 验证结果

- 新增友链可立即显示。
- 备份中不含密码和访客隐私。
- 错误备份不会删除现有数据。
- RSS 可被标准 XML 解析器正常读取。
